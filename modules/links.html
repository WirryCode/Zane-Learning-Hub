Part 2 · Module 06

Links

Anchors, hrefs, rel, targets

The <a> (anchor) element plus its href attribute makes a hyperlink: a connection between the current document and another resource. Links can also be made by <area>, <link> and forms.

1. The href attribute

href is technically optional, but it is what turns <a> into a link. Without it, <a> is just a placeholder: not focusable, not announced as a link.

<a href="https://example.com/">Absolute URL (protocol + domain)</a>
<a href="../attributes/">Relative URL (relative to this file)</a>
<a href="#teachers">Fragment: element with id="teachers"</a>
<a href="https://example.com/#teachers">Absolute URL + fragment</a>
<a href="mailto:hal@example.com">Email Hal</a>
<a href="tel:+18005551212">Call us</a>
KindNotes
AbsoluteWorks anywhere. //example.com (protocol-relative) is legacy: just use https://
RelativeNo protocol or domain; resolved against the current page (or <base>)
Fragment #idScrolls to the matching id. The fragment is not sent to the server. #top or # (empty) scroll to page top if no element has that id
mailto:Opens the mail app. Add ?subject=...&body=... (percent-encoded). Address may be omitted for "tell a friend" links
tel:Opens a dialler or call app; use international format +1...
🧠 Remember itMATH: link kindsMice Always Tickle Hippos = Mailto, Anchor (#id), Tel, Http(s).
⚡ Pro hackAuto-label links with CSSa[href^="mailto:"]::before, a[href^="tel:"], a[href$=".pdf"]::after and a[href^="http"]:not([href*="mysite.com"]) can add icons or "(PDF)" labels with no extra markup.
⚡ Pro hackTell-a-friend linkmailto:?subject=Join%20me&body=... with no address lets visitors choose recipients. Build the string with encodeURIComponent() so spaces and & survive.

2. download

Add download="suggested-name.pdf" when href points to a file you want saved rather than opened. It also works with blob: and data: URLs. It is honoured only for same-origin (or blob/data) URLs.

☠ Major fail pointCross-origin downloaddownload is ignored for files on another origin: the browser simply navigates to them. Serve a Content-Disposition: attachment header instead.

3. target: where it opens

ValueResult
_self (default)Current tab or frame
_blankNew, unnamed tab on every click
_parent / _topParent frame / top-most frame (same as _self if not nested)
any name, e.g. regOpens a tab with that name once, then reuses it

Keywords are case-insensitive; custom names are case-sensitive. Clicking target="_blank" fifteen times gives fifteen tabs; target="reg" gives one.

⚠ Common mistake_blank everywhereNew tabs break the Back button and surprise users. Use _blank sparingly, say so in the link text, and prefer a named target if repeat clicks are likely.
⚡ Pro hackPair it with rel<a href="..." target="_blank" rel="noopener noreferrer">. Modern browsers treat _blank as noopener already; adding it costs nothing and protects older ones. noreferrer also hides the Referer header.

AttributeUse

5. Good links

  • The link content is its accessible name: say where it goes ("Read the 2026 report"), not "click here" or "more".
  • If the link is an image, its alt is the link name.
  • Do not rely on colour alone: add an underline or another cue, and keep a visible focus style.
  • Never nest interactive content (<button>, <input>, another <a>) inside a link, or a link inside a <button> or <label>.
  • Enter activates a focused link. (Space activates buttons, not links.)
  • <a> may wrap block content (a whole card). document.links lists all a and area elements that have href.
⚠ Common mistakeClick hereScreen reader users often list all links out of context. "Click here, click here, more" tells them nothing.
⚠ Common mistakehref="#" as a buttonIt scrolls to the top and pollutes history. If it performs an action instead of navigating, use <button>.
☠ Major fail pointColour-only linksLinks distinguished only by colour fail accessibility checks. Removing the focus outline fails keyboard users.
