Lists

ul, ol, dl and nesting

HTML has three kinds of list. Use a list whenever you have a group of related items, even if CSS removes the bullets (navigation bars, to-do lists, quiz answers).

1. The three list types

ElementMeaningChildren
<ul>Unordered: order does not matter<li> only
<ol>Ordered: sequence matters<li> only
<dl>Description: name/value (key/value) pairs<dt>, <dd>, optional <div> groups

<menu> is also allowed to hold <li> (an unordered list for toolbars). Form lists (<select>, <datalist>, <optgroup>) are built from <option> and belong to forms.

🧠 Remember itOUD: the list trioOranges Under Desks = Ordered (ol), Unordered (ul), Description (dl).

2. ul, ol and li

  • The only valid children of <ul> and <ol> are <li> elements (plus script-supporting elements).
  • To nest a list, put it inside an <li>, never directly inside the <ul>/<ol>.
  • <ul> has no element-specific attributes. Bullet style is CSS (list-style-type).
  • <li> may contain any flow content: paragraphs, images, blockquotes, headings, even more lists.
  • The closing </li> is optional in the spec. Write it anyway: one rule, no exceptions to remember.
<ul>
  <li>Elements
    <ul>
      <li>Replaced</li>
      <li>Void</li>
    </ul>
  </li>
  <li>Attributes</li>
</ul>

3. Ordered-list attributes

AttributeOnEffect
type<ol>1 (default), a, A, i, I
start<ol>First number (default 1; can be 0 or negative)
reversed<ol>Boolean: count down
value<li>Sets this item's number; later items continue from it

CSS list-style-type overrides type. Keep type in documents where numbering style is part of the content (legal text). For purely presentational numbering use CSS counters and ::marker.

⚡ Pro hackCount anythingstart="0" or negative numbers work, and reversed plus start makes custom countdowns. <li value="n"> jumps the numbering for the rest of the list.

4. Description lists

  • <dt> is the term, <dd> the details. They were once called "definition" lists, but are for any key/value data (glossaries, metadata, FAQs of facts).
  • Pairs are not forced one-to-one: a term can have several <dd>s, and several terms can share one <dd>. Each <dt> needs at least one <dd>.
  • <dl> has no implicit ARIA role. <dt> is term, <dd> is definition.
  • Wrap each group in a <div> inside the <dl> when you need to style them as units. <template> and <script> are also allowed as children.
  • No element-specific attributes on <dl>, <dt> or <dd>.

5. Lists without bullets

Navigation bars and card grids are lists too. But list-style: none (or display: grid/flex on the list) can make Safari with VoiceOver drop the list semantics. If users benefit from "list, 5 items", add role="list" on the <ul> or <ol>.
