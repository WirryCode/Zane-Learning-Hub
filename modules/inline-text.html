Other Inline Text

em, strong, mark, time, abbr, code

HTML was built for sharing documents, so it has many small inline elements that add meaning to text. Pick them for meaning; CSS handles looks.

1. Code and technical writing

ElementUse for
<code>A fragment of code (monospace). Wrap multi-line code in <pre> to keep whitespace
<samp>Sample output from a program
<kbd>User input: keys, voice commands, any entry
<var>A variable or placeholder in maths or code (italic)
<data value="">Content plus a machine-readable value
<time datetime="">A date, time or duration. Use instead of <data> for anything time-related
<p>Press <kbd>Ctrl</kbd> + <kbd>S</kbd>. The console prints <samp>Saved 3 files</samp>.</p>
<p>Solve for <var>x</var> in <var>x</var><sup>2</sup> + 1 = 5.</p>
<p>Class starts <time datetime="2026-12-01T09:00">1 December at 9am</time>.</p>
<p>Water is H<sub>2</sub>O.</p>

For heavy maths use MathML instead of stacking <var>, <sup> and <sub>.

2. Edits and typography

  • <del> marks removed text, <ins> marks added text. Both take cite (a URL explaining the change) and datetime.
  • <s> marks content that is no longer relevant or accurate but not removed (an old price). It is not an edit record.
  • <sup> and <sub> are for typographic raising and lowering: exponents, footnote marks, chemical formulas.
  • <small> is for side comments and fine print (legal text, copyright), not just "make it smaller".

3. Definitions and language

  • Abbreviations: spell the term out on first use, then wrap the short form in <abbr>. <abbr> may mark later uses too.
  • title on <abbr> is valid, but it does nothing on touch or keyboard, so never rely on it. Skip well-known terms like HTML.
  • <dfn> marks the term being defined, inside the sentence that defines it. Add lang if it is in another language.
  • <bdi> isolates text of unknown direction (usernames); <bdo dir="rtl"> forces a direction.
  • <ruby> holds East Asian pronunciation guides: base text, <rt> (the annotation) and <rp> (parentheses shown only if ruby is unsupported).

4. Emphasis family

ElementMeaning
<em>Stress: changes the sentence's meaning when spoken. Nesting increases stress
<strong>Importance, seriousness or urgency
<mark>Relevance: highlight, e.g. a search hit
<cite>The title of a creative work
<i>Alternate voice: technical term, foreign phrase, thought, ship name. Not just "italic"
<u>Non-textual annotation, such as a flagged misspelling
<b>Draw attention with no extra importance. Last resort

5. Whitespace and void elements

  • <br> is a line break inside content (poems, address lines), not a spacing tool.
  • <hr> is a thematic break between topics (role separator), not just a line.
  • <wbr> is an optional break point inside long strings such as URLs. It adds no hyphen.
  • These are all void elements: no content, no end tag. A trailing slash (<br/>) is allowed but means nothing in HTML.
⚠ Common mistakei for icons<i class="icon-home"></i> is a common icon-font habit. <i> means an alternate voice. Use <span> (hidden from assistive tech) or an inline <svg>.
⚠ Common mistakePicking tags for looks<b> for any bold, <em> for any italic, <br><br> for paragraph spacing, <u> for emphasis. Use <strong>/<em> for meaning and CSS for style.
⚡ Pro hackAuto-highlight search hitsWrap matches in <mark> and style mark { background: gold }. Screen readers can announce the highlight, a plain <span> cannot.
⚡ Pro hackHand-break long stringsPlace <wbr> after slashes in long URLs, or use CSS overflow-wrap: anywhere for the lazy fix.
