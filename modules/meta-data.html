Meta Data

Social cards, SEO, manifest, icons

Everything in <head> is metadata: <title>, <link>, <script>, <style>, <base>. The <meta> element covers metadata those cannot express. Metadata is invisible on the page but drives search results, social cards, browser colours, installability and security.

1. How meta tags are built

FormAttributesExample
Charsetcharset only<meta charset="utf-8">
Pragma directivehttp-equiv + content<meta http-equiv="refresh" content="...">

  • charset replaced the older <meta http-equiv="Content-Type" content="text/html; charset=utf-8">. For HTML the only legal value is utf-8 (case-insensitive). Put it first in the head, within the first 1024 bytes.
  • http-equiv means "HTTP equivalent": it mimics an HTTP response header when you cannot set one.
  • name and http-equiv tags must have content.
  • The viewport meta is the other must-have: width=device-width, initial-scale=1.

2. Pragma directives (http-equiv)

  • The spec lists seven, but only a few matter: refresh, content-security-policy (and rarely x-ua-compatible, default-style). content-language is obsolete (use lang).
  • refresh reloads or redirects after N seconds: content="5; url=https://example.com/new". Avoid it. Unexpected reloads or redirects disorient users and break accessibility (WCAG timing rules). For permanent moves, use a server redirect (301/308). If you must use it, give enough time, a visible link, and a way to stop it.
  • content-security-policy limits where scripts, styles, images and frames may load from, reducing cross-site scripting: <meta http-equiv="content-security-policy" content="default-src https:">. A real HTTP header is better: the meta version cannot do frame-ancestors, report-uri or sandbox.
⚠ Common mistakeRefresh without url=content="60; https://example.com" is missing the url=. It happens to work in browsers that guess, but the correct syntax is seconds; url=....
☠ Major fail pointSilent redirectAn instant refresh redirect breaks the Back button (it bounces forward again) and confuses screen readers. Redirect on the server.

3. Named meta tags

namePurpose
descriptionThe snippet search engines often show under your title. One or two accurate sentences. Worth including.
theme-colorColours the browser's address bar or tab strip. Takes a media attribute (only this meta does) for light/dark variants.
robotsnoindex, nofollow: ask crawlers not to index the page or follow links. Index and follow are the default. A request, not a law
keywordsIgnored by search engines since it was abused with spam. Skip it.
color-schemelight dark tells the browser which UI schemes the page supports
referrer, author, generator, application-nameOccasional extras
  • Use one of each name, except theme-color with different media. If you add a legacy duplicate, put the newer one first because browsers use the first match.
  • noindex only works if the crawler may fetch the page: do not also block it in robots.txt.
<meta name="description" content="Register for a machine learning workshop for machines who cannot learn good.">
<meta name="theme-color" content="#226DAA" media="(prefers-color-scheme: light)">
<meta name="theme-color" content="#0b2540" media="(prefers-color-scheme: dark)">
<meta name="robots" content="noindex, nofollow">

4. Social cards: Open Graph and Twitter/X

When someone pastes your link into a social or chat app, it builds a card. Without metadata it uses the <title> and description. With it you choose the title, text and picture.

  • Open Graph tags use property (an extension, so it cannot clash with future name values): og:title, og:description, og:image (an absolute https URL), og:image:alt, og:url (the canonical URL), og:type, og:site_name.
  • Twitter/X cards use name with a twitter: prefix. The key one is twitter:card (summary or summary_large_image); then twitter:title, twitter:description, twitter:image and twitter:image:alt. Where a twitter: tag is missing, X falls back to the Open Graph tag.
  • The image needs alt text here too (og:image:alt, twitter:image:alt).
  • Different URLs may produce different cards, handy for campaign links.
  • Share previews are cached by each platform: use their debugger tools after changing tags.
<meta property="og:title" content="Machine Learning Workshop">
<meta property="og:description" content="School for machines who cannot learn good.">
<meta property="og:image" content="https://example.com/images/all.png">
<meta property="og:image:alt" content="Line drawing of home appliances">
<meta property="og:url" content="https://example.com/">
<meta name="twitter:card" content="summary_large_image">
🧠 Remember itTDIU: the four card basicsTigers Drink Iced Unicorn-milk = Title, Description, Image, URL (then add the card type).
⚠ Common mistakeRelative or http imageog:image="/img/all.png" or an http:// link often gives a blank card. Use a full https:// URL.
⚠ Common mistakeproperty vs name mix-up<meta name="og:title"> is not Open Graph; it must be property="og:title". Twitter tags use name="twitter:...". Mixing them is a very common silent fail.

5. Icons, app mode and the manifest

  • <link rel="icon" href="/favicon.svg" type="image/svg+xml"> (plus a PNG/ICO fallback) sets the tab icon.
  • <link rel="apple-touch-icon" href="/icons/180.png"> is the home-screen icon on iOS.
  • <link rel="apple-touch-startup-image" ... media="(orientation: portrait)">: the media value must include parentheses.
  • <meta name="mobile-web-app-capable" content="yes"> (older: apple-mobile-web-app-capable) says the page works as a standalone app. Only add it if the app really has its own navigation: no browser back button.
  • <meta name="application-name"> and apple-mobile-web-app-title give a short name for the home screen.
  • A web app manifest is a JSON file (manifest.webmanifest) holding the name, short_name, icons, colours and display mode. Link it: <link rel="manifest" href="/manifest.webmanifest">. It replaces most of the tags above for a progressive web app. Defining theme-color in HTML still helps the colour appear before the manifest loads.
  • <link rel="canonical" href="..."> tells search engines the preferred URL for duplicates. rel="alternate" hreflang="fr-FR" points to translations (add x-default).
⚡ Pro hackDark-mode theme colourTwo theme-color tags with media="(prefers-color-scheme: light)" and dark give the browser chrome the right colour in each mode. Same trick works for color-scheme.
⚡ Pro hackStructured dataA <script type="application/ld+json"> block with schema.org data lets search engines show rich results. It is metadata in the head (or body) that is never rendered.
☠ Major fail pointWrong stylesheet attribute<link rel="stylesheet" src="styles.css"> is a typo that appears in the sample: <link> takes href, not src. Nothing loads and nothing errors.
☠ Major fail pointBlocking your own pageA leftover <meta name="robots" content="noindex"> from staging is the classic reason a live site vanishes from search. Check it before launch.
