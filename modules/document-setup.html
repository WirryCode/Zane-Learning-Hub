Document Setup

Doctype, lang, head essentials, CSS, scripts, base

1. The skeleton every page needs

Every HTML document is a tree: a doctype, one root <html> element, and exactly two children: <head> (invisible information) and <body> (what people see). Browsers will still render a page that is missing these, but they will guess, and guessing is how bugs are born.

🧠 Remember itDL-CTV: the five must-havesDogs Like Chasing Tiny Vans = Doctype, Lang, Charset, Title, Viewport. If your page has all five, it passes the "professional start" test.

2. Doctype: standards vs quirks

<!DOCTYPE html> is not a tag; it is a special doctype node. It must be the very first thing in the file. It tells the browser to use standards mode. Without it the browser falls into quirks mode, an emulation of 1990s browser behaviour that changes box sizing, table inheritance and more.

☠ Major fail pointDoctype missing or not firstA blank line is fine, but a comment, a stray character, or an XML declaration before the doctype can push some browsers into quirks mode. Symptom: CSS that "works everywhere except this page".

3. The lang attribute

lang on <html> declares the page's main human language using an ISO code plus an optional region, for example en, en-GB, fr-CA, sw. Screen readers use it to pick the right pronunciation, search engines use it for indexing, and translation tools use it to decide whether to offer a translation.

You can override it on any element for a passage in another language. It has no visual effect, but it can be targeted in CSS.

<p>She said: <span lang="fr-FR">Ceci n'est pas une pipe.</span></p>

/* CSS: two ways to target French content */
[lang|="fr"] { font-style: italic; }
:lang(fr)    { color: #A51C30; }
⚡ Pro hackRegion codes matterfr-CA and fr-BF (Canada vs Burkina Faso) can differ in pronunciation and quotation marks. Use the plain language code (en) unless the region really changes something.
✎ Notes corrected: the original notes show <span lang='fr-fr"> with mismatched quote marks. Always open and close attribute values with the same quote character.

4. Inside the head: the big three

Character encoding

<meta charset="utf-8"> must be the first child of <head> (and within the first 1024 bytes of the file) so the browser knows how to decode everything after it, including the title. The old default in many browsers is windows-1252, which turns "é" and emoji into garbage. UTF-8 handles every character using one to four bytes.

Title

<title> appears in the tab, history, bookmarks, search results and social cards. Each page needs a unique title. Avoid emoji in titles: screen readers read them aloud and they are inaccessible.

Viewport

Without <meta name="viewport" content="width=device-width, initial-scale=1">, phones pretend to be about 980px wide and shrink your page. This one line is what makes responsive CSS work.

⚠ Common mistakeDisabling zoomAdding user-scalable=no or maximum-scale=1 stops people pinching to zoom. That fails accessibility audits (Lighthouse flags it). Leave scaling alone.
✎ Notes corrected: the notes' example <meta name='viewport" ...> mixes ' and ". Use matching quotes. The notes also use two different domains for the same fictional site (machinelearningworkshop.com and machinelearning.com); a canonical URL must be identical everywhere.

5. Adding CSS

MethodWhereUse when
<link rel="stylesheet" href="styles.css">headDefault choice. Cached across pages, one place to maintain.
<style>...</style>headSmall pages, critical CSS, custom properties, @import ... layer().
style="..." attributeany elementOne-off overrides and quick tests. Hard to maintain, high specificity.

Put styles in the head: the browser then knows how to paint content the first time, avoiding a flash of unstyled content and repaints.

☠ Major fail pointForgetting rel<link href="styles.css"> without rel="stylesheet" links nothing and fails silently. rel defines the relationship; no relationship, no CSS.
⚠ Common mistake@import in the wrong place@import rules must be the first statements in a stylesheet or <style> block (only @charset may come before). Placed later, they are ignored. Syntax for a cascade layer: @import "styles.css" layer(base);

6. link rel: icons, alternates, canonical

<link rel="icon" sizes="32x32" type="image/png" href="/images/icon.png">
<link rel="apple-touch-icon" sizes="180x180" href="/images/icon-180.png">
<link rel="alternate" href="https://example.com/fr/" hreflang="fr-FR">
<link rel="alternate" type="application/rss+xml" href="/feed.xml">
<link rel="canonical" href="https://example.com/">
  • icon: the favicon. If you declare none, browsers look for /favicon.ico in the site root.
  • apple-touch-icon: used only when someone adds your site to an iOS home screen. mask-icon is a monochrome SVG for pinned tabs in desktop Safari.
  • alternate: translations (needs hreflang), feeds (needs type), or alternate stylesheets (needs title).
  • canonical: tells search engines which URL is the authoritative copy when the same content lives at several addresses.
🧠 Remember itICAC: link rel valuesIce Cream Always Cheers = Icon, Canonical, Alternate, CSS (stylesheet). Add manifest and preload for later modules.

7. Scripts: defer, async, or bottom

A plain <script> blocks parsing: the browser stops, downloads, runs it, then continues. Three ways to avoid the pain:

Before </body>after contentwhen reachedyes
🧠 Remember itDAD: Defer After Documentdefer = runs After the Document is parsed, in order. async = runs As soon as it Shows up, any order (analytics, ads).
☠ Major fail pointdefer on an inline scriptdefer and async only work on scripts with a src. On an inline <script> they do nothing. Scripts with type="module" are deferred automatically.
⚡ Pro hackModern default<script src="app.js" defer></script> in the head is the cleanest pattern: it downloads early, runs late, and keeps order.

8. The base element

<base href="https://example.com/" target="_top"> sets the base URL for every relative link and a default target for links and forms. Rules: only one per document, and it must appear before any relative URL.

☠ Major fail pointbase breaks fragment linksWith <base> present, <a href="#top"> resolves against the base URL, so it triggers a page load of the base address with #top appended instead of jumping within the page. Many developers avoid <base> for this reason.
⚡ Pro hackTargets_self (default) same context, _blank new tab, _parent parent frame, _top whole tab. When using _blank on links, add rel="noopener" (modern browsers imply it, but old habits are safe).
