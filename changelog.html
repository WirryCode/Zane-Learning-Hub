Changelog

What was corrected in each module, and why

These notes were rebuilt from the original course text. Every module lists the corrections made while restoring it: places where the source notes were out of date, wrong, or missing something the exam expects. Nothing was invented; each entry names what changed.

M01 Document Setup

the original notes show <span lang='fr-fr"> with mismatched quote marks. Always open and close attribute values with the same quote character.

M02 Text Basics

the notes say you "generally do not need" &gt;, " or &amp;. In practice, always escape &amp; in text and URLs (?a=1&amp;b=2): a bare & followed by letters can be read as the start of an entity. > and " are safe in plain text but " must be escaped inside a double-quoted attribute. Also, the notes call the nested-landmark exercise "Oceana"; the region is spelled Oceania.

M03 Headings & Sections

the notes sometimes write <headers>; the element is <header> (singular). And "the holy grail layout" means header, main content, two sidebars, footer, and the markup order shown is correct for source order, with CSS handling positioning.

M04 Semantics

the notes call the AOM "a semantic version of the DOM". More exactly, it is the accessibility tree browsers derive from the DOM and computed style, so display:none removes nodes from it. Also, the notes' Firefox shot labels a <header> nested in <main> as a "section": it is not a landmark (ARIA calls it generic).

M05 Navigation

the notes' code has mismatched quotes (aria-label="breadcrumbs'", href="/learn'), and shows aria-selected="true" on a link: that attribute is invalid for links, so use only aria-current. The JS url.pathname.split('/) is missing a quote and yields an empty first segment (use .split('/').filter(Boolean)). Also, the claim that attribute text "may not be translated" depends on the tool; visible text is simply safer. Removed: web.dev page walkthroughs and Yahoo!/Google examples.

M06 Links

in the notes: rel="alternative" is actually rel="alternate"; type="application/x-pdf" should be application/pdf; tel:8005551212 should be international (tel:+1...); the JS example sets a.protocol = 'ftp' but FTP support has been removed from browsers (use https); xlink:href on SVG links is deprecated (SVG 2 uses plain href); ping is disabled by default in some browsers; quote typos such as href="mailto:...'. Removed: web history trivia, SVGOMG and Canvas demos, Jake Archibald references.

M07 Lists

the notes say headings inside list items make the item "sectioning content". Wrong: a heading is heading content; <li> simply allows any flow content. Typos fixed: <dd&gt; mangled entity, alt="Vaccuum' (vacuum, mismatched quote). Removed: CodePen iframes and the MLW (Machine Learning Workshop) joke-page walkthrough. Added: <menu>, nesting rule, value/reversed interplay, the <p> parsing trap.

M08 Other Inline Text

the notes say <abbr> is needed "only on this first occurrence" and that title is "not helpful": the real rule is to spell out on first use and mark abbreviations as needed, while title is valid but unreliable. <cite> is for the title of a work, not an ISBN or a person's name. <ruby> is for East Asian text; the claim that it covers Hebrew, Arabic and Vietnamese was removed. <wbr/> is a void element (no slash needed). The <address> postal example is only valid as contact info for the page or article owner. <i>, <b> and <u> were never really "deprecated": they were redefined. Removed: CodePen embeds, the W3C bidi link.

M09 Images

the notes say "the lazy attribute enables lazy loading": it is loading="lazy". They say a width-based srcset needs a sizes entry for each option except the last: sizes actually lists display-width conditions (the last has no condition), and defaults to 100vw if absent. srcset is also used by <link> as imagesrcset. <source>'s media is its own attribute, not a part of srcset. fetchpriority is no longer Blink-only. role="img" on SVG <img> is a legacy VoiceOver workaround, and role="none" beside alt="" is redundant. <input type="image'> and alt="Vaccuum' have quote typos. Removed: site-specific page walkthroughs, joke alt-text examples, Learn-course plugs.

M10 Tables

the notes' <th scope="row'&gt;Lou Minious&lt;/th> is mangled (mismatched quote, escaped tag); the default scope is auto (the browser infers col or row), not simply col or row; rowgroup/colgroup are valid values and auto was missing; the "tfoot must come before tbody" detail is a legacy HTML 4 rule. Removed: CodePen iframes, the MLW-students walkthrough, the slidedeck link, "Learn CSS" plugs, the quiz.

M11 Attributes

the notes say required="required" "is not a valid value": it is valid (a boolean attribute may be empty or equal its own name). setAttribute("muted") needs a second argument (""). The toggle example if (editor.contentEditable) is always true (the property is a string): use isContentEditable. The role attribute is defined by ARIA but is fully part of HTML's attribute model. "Custom properties" in the dataset passage means custom data attributes; plaintext-only and hidden="until-found" were missing; autofocus is a global boolean. Quote typos (type="Text'", dataset["machineLearning'], e.dataset for el.dataset) and OCR-looking getElementByld fixed. Removed: CodePen iframes, MLW light-switch easter egg, share-action custom element, site-specific quiz.

M12 Forms

the notes call <form> "a landmark": only a form with an accessible name is. <ul start="6"> should be <ol start="6"> (start belongs to <ol>). Step mismatch makes a control :invalid and sets stepMismatch, but :out-of-range only reflects min/max. setCustomValidity() is a method of the control, not of ValidityState. :user-invalid/:user-valid are now widely supported. maxlength/minlength errors apply to user-edited values only. Quote typos (value="Submit Form', name="name') fixed. Removed: MLW April-Fools story, keyboard screenshot captions, the "Prettier requires the slash" claim (a style choice, not a rule), CodePen iframes, Learn Forms/Accessibility plugs, the quiz.

M13 Focus

the notes call non-interactive elements "inert", which clashes with the global inert attribute: here "inert" means "not interactive" and inert is the attribute. They say autofocus should be skipped "because earlier elements are skipped": the tab starting point moves, so earlier content is reached by Shift+Tab. "Avoid preventScroll" softened (it is fine when the element is already visible). disabled also covers <button>, <option>, <optgroup> and form-associated custom elements; inert also blocks text selection. Removed: web.dev share-action and navigation-drawer custom element code, CodePen iframes, Learn CSS plugs, the quiz.

M14 Meta Data

the sample uses <link rel="stylesheet" src=...> (must be href), <meta ... content="#226DAA'"> and <meta name='"robots" quote typos, og:image on http:// while the text says https, and a canonical for a different domain than the rest of the site. refresh is missing url=. media="orientation: portrait" needs parentheses. The notes omit twitter:card, the required Twitter/X tag; twitter:image:src is an old name for twitter:image. "Twitter's Card Validator" is no longer the main tool. apple-mobile-web-app-capable is the legacy name of mobile-web-app-capable. The "charset was created because developers mistyped the content attribute" story is folklore, so it is not repeated. The claims that Firefox and Opera use the description as the bookmark text are unreliable and dropped. Removed: MLW and Zoolander jokes, personal and conference social handles, PerfMatters examples, CodePen-style screenshots, the quiz.

M15 Audio & Video

the notes say booleancontrols (typo for the boolean attribute controls), mute (the attribute is muted), kind="caption" and kind="description" (plural: captions, descriptions) and list the fifth track kind as "other metadata" (it is just metadata). They say poster is "an image if the browser doesn't support video" in the quiz: it is the image shown before playback. <track lang="fr-fr"> is invalid: <track> uses srclang. Mismatched quotes (poster="images/machine.jpg', type="video/webm') fixed. Added: the fallback-content reality, canPlayType, play() as a Promise, muted attribute vs property, prefers-reduced-motion, WCAG 2.2.2, descriptions for non-screen devices, audio needing a transcript. Removed: Jake Archibald codec link, "learn accessibility" plugs, CodePen/quiz text.

M16 Details & Summary

the source title says "Summarises": the element is <summary> (module title is "Details & Summary"). "Collapsed content is not part of the DOM" is wrong: it is in the DOM but not rendered (that is why find-in-page can open it). The notes claim <summary> accepts "heading content": it accepts phrasing content, optionally with headings (accessibility caveat added). The Safari keyboard note was softened: it depends on settings. "Space between each dialog" is a slip for each <details>. The notes omit the name attribute (exclusive accordions) and beforetoggle/details:open, now added. The source says the toggle event "is fired when toggled": it fires after the change and does not bubble. Removed: web.dev "On this page" references, jQuery history aside (shortened), CodePen iframes, quiz.

M17 Dialog

"modal-less" in the source means non-modal. The source says returnValue is set to the button's "name": it is the button's value. The source says an autofocus "skips" earlier elements; the Tab starting point moves and Shift+Tab still reaches them (same fix as the Focus module). "Opening with the open attribute" is non-modal and gives no backdrop or inertness. method="dialog" consistency with the Forms module kept. Added: display override fail, top layer, cancel/close events, close(value), requestClose/closedby, Escape not closing non-modals, InvalidStateError, UA colour defaults. Removed: CodePen iframes, quiz, Focus lesson reference text.

M18 Template, Slot & Shadow

the source says a custom-element name is "recommended" to be lowercase with a dash: the hyphen is required by the spec. It says the element's contents "will be replaced by a shadow root": light-DOM children are not replaced, they remain in the DOM and are rendered only through slots. "In terms of specificity, the global CSS wins" is a cascade-context rule (outer styles beat :host), not specificity. <rating> is called an unknown element: right, but <star-rating> is a not-yet-defined custom element, not unknown. A <legend> placed inside a <slot> in a <fieldset> may not be treated as the fieldset's legend by every browser/assistive tech: use a plain element with aria-labelledby where accessibility matters. The source says shadowRoot is "an interface rendered separately": the interface is ShadowRoot, reached via el.shadowRoot. Mismatched quotes (name='star-rating-legend") fixed. attachShadow limits, closed mode, ::slotted depth, exportparts, lifecycle callbacks, form association and declarative shadow DOM added. Removed: CodePen iframes, Google checklist plug, quiz.

M19 HTML APIs

the notes say the tree shown in browser tools is the accessibility tree: the Elements panel shows the DOM, and the accessibility tree is a separate view. They say "parent methods and properties override children": it is the reverse, the inheriting (child) interface's member overrides the inherited one (this is also why HTMLOptionsCollection.length can be written while HTMLCollection.length cannot). "Document also inherits from HTMLDocument" is backwards: HTMLDocument inherits from Document. The Drag and Drop and Fullscreen APIs "inherit from Element": they are surfaced through events and methods on elements and the document, not inheritance. window.resizeTo() is shown as a general tool but only works on script-opened windows. shadowRoot "interface" is ShadowRoot. "AOM is based off the DOM" restated (see Semantics). The source chapter called "HTML APIs" covers only the DOM interfaces, so Web Storage, Fetch, Geolocation, Drag and Drop, History, Canvas, observers, Popover and secure-context/permission rules were added. The two uploaded APIs PDFs were identical except one OCR character. Removed: CodePen/quiz text.

M20 HTML Performance

the notes gave no numbers for TTFB or caching: added the TTFB 0.8 s "good" guide and clarified that no-cache means "revalidate". "Five minutes for static HTML" and "Brotli about 15 to 20% better than gzip" were checked and kept as sensible rules of thumb, not guarantees. The notes stop at the server and CDN: the markup side (lazy, fetchpriority, preload and preconnect, async/defer, width/height, srcset, DOM size) and the Core Web Vitals (INP replaced FID in March 2024) were added. The notes imply compression is always good: not for already-compressed files, and small files gain little. Removed: ismyhostfastyet.com and CrUX promotion, "Optimize TTFB", "CDN guide" and "critical path" plugs, the caching demo iframe, quiz. Module blurb in build.py ("TTFB, caching, compression, CDN") should be widened in the next stage.
